// PROJECT — VISIONIQ: INTELLIGENT CCTV MONITORING SYSTEM

Architecture

Two-stage ML pipeline: YOLOv8-s for real-time object detection (persons, vehicles, objects) on camera frames, feeding an LSTM Autoencoder that learns normal motion and occupancy sequences per zone. Reconstruction error on incoming sequences is the anomaly signal — no labelled incident data required. Frames streamed via Kafka, scored via FastAPI, tracked in MLflow.

VSS / ACAM / ISMS integration

Designed as the AI intelligence layer on top of existing physical security infrastructure. VSS camera feeds are the input source. ACAM badge events are correlated with camera detections to surface compound alerts (e.g. motion without badge log). ISMS receives scored anomaly events. HVM sensors feed the same Kafka ingestion pipeline.

Results

LSTM-AE achieves 0.947 AUROC and 0.923 recall on held-out anomaly sequences — trained exclusively on normal patterns, no labelled attack data required. 5 architectures benchmarked in MLflow. FastAPI inference at sub-100ms per frame. Operator dashboard shows live bounding boxes, per-zone anomaly scores, and a detection event log with ACAM cross-reference.
